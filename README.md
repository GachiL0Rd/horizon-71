# Горизонт 71

Интерактивная карта объектов капитального строительства Тульской области, введённых в эксплуатацию. Проект сделан как компактный MVP для хакатона: каталог, фильтры, карта, карточка объекта, проверяемые источники и пешая доступность.

## Запуск

1. Скопировать `.env.example` в `.env`.
2. Указать `YANDEX_MAPS_KEY`.
3. Запустить `npm start`.
4. Открыть `http://127.0.0.1:8080`.

`.env` исключён из Git. Сервер читает ключ и отдаёт JavaScript API Яндекс Карт по маршруту `/api/yandex-maps.js`; маршрут `/api/config` ключ не возвращает. JavaScript API исполняется в браузере, поэтому в кабинете Яндекса всё равно нужно ограничить ключ разрешёнными доменами.

## Что работает

| Возможность | Реализация |
| --- | --- |
| Каталог | 95 записей исходного архива, поиск и фильтры по отрасли, району и году ввода |
| Карта | Яндекс Карты 2.1, кластеры, отраслевые метки, спутниковая подложка |
| Карточка | Сведения из архива, сроки, участники, ссылки на публикации и поиск в ЕИС |
| История | Только подтверждённые фотографии и публикации; при отсутствии материала показывается честное сообщение |
| Доступность | Пешеходная изохрона 10 или 15 минут через Valhalla и OpenStreetMap |
| Аналитика | Сводные показатели по текущей выборке и выгрузка JSON |
| Обращение | Помощник готовит текст для официальной Платформы обратной связи, не хранит его и не имитирует ответ ведомства |

Расчёт социальной обеспеченности намеренно не показывается до загрузки населения, реестра действующих учреждений, их мощности и утверждённых нормативов.

## Структура

```text
data/objects.json    нормализованный архив объектов
js/app.js            интерфейс и сценарии карты
js/map.js            адаптер Яндекс Карт
server.mjs           статический сервер, прокси карты и изохроны
routing.mjs          Valhalla и кэш изохрон
docs/ROADMAP.md      следующий этап развития
```

План интеграций и требования к данным находятся в [docs/ROADMAP.md](docs/ROADMAP.md).
