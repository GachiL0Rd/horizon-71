# Горизонт 71 · Тульская область

MVP интерактивной карты объектов капитального строительства. Vanilla JavaScript, обычный CSS, Яндекс Карты 2.1. Node.js обслуживает файлы и небольшой API пешей доступности; runtime-зависимостей нет. React, сборщик, БД и платный Isochrone API не нужны.

## Запуск

Требуется Node.js 22+. Из папки проекта:

```sh
npm start
```

Открыть **http://localhost:8080**. Для запуска приложения `npm install` не нужен. В текущем рабочем каталоге ключ карты уже настроен в `.env`, который исключён из Git. При переносе проекта скопировать `.env.example` в `.env` и заполнить `YANDEX_MAPS_KEY`, либо ввести ключ через шестерёнку в интерфейсе. Ключ JS API по своей природе виден браузеру; ограничьте его доменами в кабинете Яндекса.

По умолчанию сервер слушает только локальный компьютер. Для демонстрации в локальной сети задать `HOST=0.0.0.0` в `.env`, перезапустить сервер и разрешить адрес сайта в настройках ключа. Для публикации необходим доступный хостинг Node.js и HTTPS. Развёртывание в интернете не выполнялось.

| Контракты | Архивные участники и сроки, поиск ЕИС, кандидат извещения по школе «Суворовский-2», отдельная стоимость из публикации | Это не подтверждённый контракт ЕИС. Автоматической синхронизации нет |
| Аналитика | Итоги по годам / отраслям, качество данных, экспорт текущей выборки | Сводка по предоставленному архиву, не по всем стройкам региона |

Задания 5 и 6 (удовлетворённость граждан и обращения) отложены по согласованному приоритету.

## Демонстрация за 3 минуты

1. Открыть карту: 53 введённых объекта. Выбрать год или отрасль; показать синхронизацию списка и меток.
2. Сбросить фильтры. Открыть первую запись — детский сад на 160 мест в Заокском. Во вкладке «История» показать фотографии «В процессе» и «После» с источниками. «До» честно обозначено как отсутствующий материал.
3. Во вкладке «Доступность» показать 10 и 15 минут. Это расчёт по дорогам, не окружность; результаты этого объекта сохранены заранее.
4. Открыть «Обеспеченность». Тула, учебное население 10 000, норма 100, мощность 700 → 70%. Изменить мощность на 1000 → 100%, цвет территории изменится. Объяснить, какие ведомственные данные заменят учебные значения.
5. Выбрать «Все объекты», найти «Суворовский 2». В «Контракте» показать сроки, найденное извещение ЕИС и стоимость из отдельного источника. Объяснить отличие опубликованной стоимости от проверенной цены контракта.
6. Показать аналитику и повторяемый импорт как основу развития.

## Данные и импорт

```sh
python scripts/import.py
```

Python нужен только при обновлении данных. Импорт читает исходный CSV (35 колонок и три строки заголовка), нормализует справочники и пишет `data/objects.json`. Исходники не меняет. Нулевые заглушки переводятся в неизвестные значения; готовность 0% сохраняется. Готовность 100% не приравнивается к вводу. Плановый год и фактический год раздельные.

ID — хеш исходного названия: стабилен при перестановке строк. Переименование меняет ID; перед регулярным промышленным импортом нужен официальный идентификатор ОКС. Дополнения `data/enrichment.json` сопоставлены по номеру исходной строки — это соглашение только для текущего снимка архива. При замене архива необходимо проверить сопоставления.

`data/enrichment.json` хранит фотографии, публикации и дополнительные сведения отдельно, не перезаписывая поля архива. Добавить фотографии можно через записи `media` с полями `stage` (`before`, `during`, `after`), `url`, `caption`, `date`, `credit`, `sourceUrl`, затем запустить импорт. Локальные изображения можно положить в `assets/`. Внешние фотографии загружаются с сайтов источников; доступность и права на дальнейшее использование следует уточнить перед публикацией продукта.

Общая мощность не суммируется: в архиве смешаны места, объёмы и другие единицы. Дата актуальности исходного архива неизвестна. Полная атрибуция границ и источники — `data/sources.json`.

## Бесплатные изохроны

`GET /api/isochrone?id=<id>&minutes=10|15` принимает только ID из архива с координатами. Один внешний запрос получает оба контура. Valhalla использует `costing=pedestrian`, `reverse=true`: зона, из которой можно дойти **до** точки. Координата из архива может не совпадать со входом, а сеть OSM может быть неполной.

Результаты сохраняются в `.local/isochrones.json`, ключ кэша включает координаты, профиль и направление. Запросы к внешнему сервису ограничены: не чаще одного за 1,2 секунды. Кэш не имеет автоматического срока годности: дата расчёта всегда отображается. Для обновления результатов архивируйте/удалите соответствующие записи кэша и демонстрационного набора, затем перезапустите сервер.

В `data/isochrones.json` включены расчёты для трёх демонстрационных объектов: детсада в Заокском (строка 1), детсада в Юго-Восточном микрорайоне (4), детской школы искусств в Заокском районе (55). Поэтому эти расчёты не зависят от доступности Valhalla при показе; Яндекс Карты по-прежнему требуют интернет. Скрипт `node scripts/prepare-demo.mjs` подготавливает только эти три объекта при работающем сервере.

Публичный сервер FOSSGIS предназначен для небольшого использования и демонстраций. Нет массового предварительного расчёта. Перед публичным запуском приложения выполните условия провайдера, в том числе уведомление владельцев сервиса, либо разверните собственный Valhalla и задайте `VALHALLA_URL`. Уведомления владельцам сервиса автоматически не отправлялись.

## Структура

```text
index.html / styles.css    интерфейс без сборки
js/app.js                 состояние, фильтры, карточки, аналитика
js/map.js                 адаптер Яндекс Карт 2.1
js/data.js                фильтрация, форматирование, расчёт обеспеченности
js/media.js               оригинальные условные SVG-схемы
server.mjs                статические файлы и HTTP API
routing.mjs               Valhalla, ограничение запросов и кэш
scripts/import.py         повторяемый импорт CSV
data/                     нормализованный архив и источники
tests/                    проверки данных, интерфейса и HTTP-маршрутов
```

В API 2.1 координаты `[широта, долгота]`, в GeoJSON — `[долгота, широта]`. Преобразование изолировано в `js/map.js`. Выбран API 2.1: предоставленный ключ принят им и проверен на реальной карте; API 3.0 с этим ключом вернул 403.

## Проверки

Тестовые зависимости нужны только разработчику:

```sh
npm ci
npx playwright install chromium
npm test
npm run test:e2e
```

Для проверки настоящей карты, фотографий и изохроны при работающем сервере:

```sh
npm run check:live
```

Скриншоты сохраняются в `.local/`. Основные браузерные тесты изолируют внешний сервис карт, чтобы проверить каталог даже при сетевом сбое. Live-проверка отдельно использует настоящий Яндекс API и реальный расчёт доступности.

2. Согласовать идентификаторы объектов, загрузить лицензированные архивные материалы, подтвердить контракты ЕИС.
3. Перенести JSON в PostgreSQL; сохранить формат ответа для клиента. PostGIS добавить при появлении пространственных запросов.

MVP не содержит аккаунтов, сбора жалоб, персональных данных и фиктивной отправки обращений.
