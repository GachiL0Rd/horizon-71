# Развитие «Горизонта 71»

## Следующий практический этап

1. Ввести постоянный идентификатор объекта и журнал обновлений: это позволит безопасно сопоставлять записи между выгрузками.
2. Проверить координаты всех объектов без точки на карте и хранить источник каждой координаты.
3. Добавить проверенные ссылки на карточки закупок и контрактов ЕИС. Автоматическое сопоставление допускается только как черновик для редактора.
4. Подключить официальную Платформу обратной связи по согласованному виджету или API. До этого карта лишь помогает подготовить текст обращения и не хранит персональные данные.

## Данные для полезной аналитики района

Расчёт социальной обеспеченности появится после загрузки трёх согласованных наборов: населения по муниципалитетам и периодам, действующих учреждений с проектной мощностью и утверждённых нормативов по каждой отрасли. Расчёт должен сохранять дату среза, единицы измерения и ссылку на источник.

## Путь к рабочему сервису

Для регулярного обновления понадобится небольшая серверная часть с PostgreSQL, импортом проверенных выгрузок, ролями редактора и аудитом изменений. Карточка объекта должна показывать дату обновления и происхождение каждого значимого поля. Затем можно добавить подписки на изменения, публичные ссылки на объект и выгрузку открытых данных.

## Что не следует имитировать в презентации

Не стоит показывать вымышленные фотографии, обращения, ответы ведомств, рейтинги или показатели обеспеченности. Если данных пока нет, интерфейс должен явно назвать недостающий источник и следующий шаг интеграции.
